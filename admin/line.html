The line

Each rabbit's line in the order the database took the requests. Match a text to its row by the code in it (like K7Q2): places move up when one ahead is passed, codes never change. The same code in two lines is one browser that asked for both (usually one person, on one phone). Tap Called when you call someone: the row then shows when their hour ends. Nothing happens by itself; you mark Paid or Passed. A code that never reached you by text has nobody to call: pass it when it comes to the front. Passed places stay on this page for 60 days.
